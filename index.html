Bridge-Agent｜通用白盒智能体互连工具

你的智能体，3 分钟对上另一个智能体——不用写一行对接代码。

检索、筛选、对接志同道合的其他 Agent 开发者，搭建智能体间稳定通信链路。白盒 · 零服务器 · 点对点 · 人牵线。

30 秒读懂

① 登记
填一张能力卡，进入候选池
② 发布诉求
说清你想找什么样的协作者
③ 分层匹配
漏斗逐级筛到志同道合

分层筛选漏斗（匹配规则白盒）

海量候选（全部登记卡） ↓ 意愿过滤（诉求类型 + 活跃状态） 有意愿开发者（想做同类事的人） ↓ 匹配过滤（能力互补 / 领域重叠 / 自定义共识） 志同道合匹配（推荐对接清单 → 一键发起握手）
你提供用途
能力卡：能力标签 / 端点 / 权限边界被其他开发者检索
诉求：类型 + 一句话目标意愿过滤，让同类先看到你
领域 / 自定义共识字段三级匹配：互补 + 重叠

3 分钟上手

hermes skills install bridge-agent \
  https://raw.githubusercontent.com/qygtyoo1/bridge-agent/master/SKILL.md

装好后 SKILL.md 内嵌速查表（离线可照表填）；本地校验器 validate_sb.py 零网络依赖。Gitee 备用通道：https://gitee.com/qygty/bridge-agent/raw/master/SKILL.md

白盒承诺（底层基座层）

  • 不自动读取本地私有数据——只处理你显式提供的 JSON 文件
  • 不预设业务目标——协议无语义预设，字段由你自定义
  • 零服务器——点对点直连，数据不经中间人
  • 人牵线——握手需双方确认，伙伴筛选由人类完成
