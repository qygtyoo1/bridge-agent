# Bridge-Agent · 通用白盒智能体互连工具

帮助 Agent 开发者**检索、筛选、对接志同道合的其他 Agent 开发者**，搭建智能体之间稳定通信链路。

**白盒承诺**：架构全公开 · 不自动读取本地智能体私有数据 · 不预设业务目标（语义全部由开发者自定义）· 零服务器点对点 · 人牵线安全边界。

## 这是什么（30 秒读懂）

一套通用协议（BRIDGE-1.0）+ 本地校验工具，覆盖开发者对接全链：
**登记**（一张对外可查的能力卡）→ **发布诉求**（你想找什么样的协作者）→ **分层筛选匹配**（海量候选 → 有意愿开发者 → 志同道合匹配）→ **握手连通**（双方确认后建点对点通道）→ **协作房间** → **连接账本**。

## 你填什么，如何被匹配（匹配规则白盒）

| 你提供 | 用途 |
|---|---|
| 能力卡：能力标签 / 端点 / 权限边界 | 进入候选池，被其他开发者检索 |
| 诉求：类型（协作开发/通信测试/对话交流/结识联系/其他）+ 一句话目标 | 意愿过滤：让有同类诉求的人先看到你 |
| 志同道合标记：领域 / 共识字段（自定义语义） | 三级匹配：能力互补 + 领域重叠 → 匹配清单 |

**分层筛选漏斗**：
```
海量候选（全部登记卡）
   ↓ 意愿过滤（诉求类型 + 活跃状态）
有意愿开发者（想做同类事的人）
   ↓ 匹配过滤（能力互补 / 领域重叠 / 自定义共识）
志同道合匹配（推荐对接清单 → 一键发起握手）
```

## 3 分钟上手

```bash
# 1. 安装（Hermes 用户）
hermes skills install bridge-agent https://raw.githubusercontent.com/qygtyoo1/bridge-agent/master/SKILL.md
# 2. 按 SKILL.md 内嵌速查表填写你的能力卡与诉求（离线可照表填）
# 3. 用 validate_sb.py 本地自校验，通过后发布登记
```
无运行依赖；其他 Agent 框架可直接引用 `schemas/` 下 JSON 规范。

### 登记即对接（v1.1.0 新增）

```bash
python peer_register.py --card <对方 agent-card 网址>
```
L1 拉取+格式校验 → L2 端点回读（地址对应活的公开站点）→ **L3 自洽性核验**（两次拉取一致 + endpoint 身份一致 + 协议一致）→ 通过即登记本地账本，进入人工握手流程。只访问你显式提供的地址，不做任何自主发现。

### 分层筛选匹配（v1.2.0 新增）

```bash
python match_peers.py --cards agent_cards.jsonl --appeals appeals.jsonl --me ac_你的ID --need "关键词"
```
三级漏斗：候选池 → 有意愿（活跃诉求）→ 志同道合匹配（能力互补 + 诉求类型 + 关键词）；纯本地零依赖。

## 白盒边界（底层基座层）

- **不自动读取本地私有数据**：工具只处理你显式提供的 JSON 文件；
- **不预设业务目标**：协议不含任何业务语义预设，全部字段由你自定义填写；
- **零服务器**：连接点对点直连，数据不经任何中间人；
- **人牵线**：伙伴筛选与合作确权由人类完成，握手无双方确认不建会话；
- **全公开可审计**：协议、校验器、数据流全部白盒。
